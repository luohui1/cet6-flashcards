# 六级闪卡

一个背单词的 Android App：先速览，再打乱顺序闪卡；按反应速度定级，按复习阶梯（第 2、3、5、8、16、31 天）安排复习。

**下载：** 到 [Releases](https://github.com/luohui1/cet6-flashcards/releases/latest) 下载最新的 APK 安装。装好后，App 每次打开都会检查这里的新版本并提示更新。

## 词书

- 六级核心词汇（Phase 1–5，960 词，带词根词缀拆解）
- 四级核心词汇、四级大纲词汇、六级大纲词汇、考研大纲词汇
